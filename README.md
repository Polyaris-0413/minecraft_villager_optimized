# VillagerOptimized

A lightweight Fabric mod for Minecraft 1.21.1 that expands villager-related mechanics

## Features

- Villagers no longer trample farmland
- Farmer villagers repair trampled farmland in the water-fed area around their composter
- Villagers regenerate health while sleeping
- Armorer, Toolsmith, and Weaponsmith villagers can repair Iron Golems

## Installation

You can get the mod file from [GitHub Releases](https://github.com/Polyaris-0413/minecraft_villager_optimized/releases/latest) or [Modrinth](https://modrinth.com/mod/villager_optimized), and place it in the corresponding game directory
